# 创意故事开头生成器

## 提示词内容

请根据以下要素，创作一个引人入胜的故事开头（约200-300字）：

**故事类型：** [在这里指定故事类型，如：科幻、奇幻、悬疑、爱情等]

**主角特点：** [在这里描述主角的主要特点]

**背景设定：** [在这里描述故事发生的时间和地点]

**关键元素：** [在这里列出1-2个必须在开头中出现的关键元素]

请确保开头能够：
1. 立即吸引读者注意力
2. 建立故事的基本氛围
3. 暗示即将发生的冲突或事件
4. 留下足够的悬念，让读者想要继续阅读

## 使用指南

### 使用场景
- 当您需要开始一个新故事但缺乏灵感时
- 作为创意写作练习的起点
- 突破写作瓶颈的工具

### 输入要求
- 故事类型（必需）
- 主角特点（必需）
- 背景设定（必需）
- 关键元素（可选，但建议提供）

### 预期输出
- 200-300字的故事开头
- 符合指定类型和要素
- 具有吸引力和悬念

### 使用技巧
- 尝试不同的故事类型组合，获得多样化的开头
- 如果对结果不满意，可以微调输入要素后再次生成
- 将生成的开头作为基础，进一步发展成完整故事

## 示例

### 示例1
**输入：**
```
故事类型：科幻悬疑
主角特点：一位失去记忆的科学家
背景设定：2150年的月球研究基地
关键元素：一本神秘的日记，一段无法解释的录音
```

**输出：**
```
当艾琳娜博士在月球基地的医务室醒来时，第一个映入眼帘的是陌生的白色天花板。她的头痛得厉害，仿佛有人用锤子在她的颅骨内敲打。更糟糕的是，她记不起自己是谁，也不知道为什么会在这里。

房间角落里，一本破旧的日记本静静地躺在金属桌上，封面上没有名字，只有一行潦草的字迹："不要相信他们"。她挣扎着起身，桌上的通讯器突然闪烁起来，一段断断续续的录音播放着："...实验失控...记忆清除...你必须..."

艾琳娜握紧了日记本，心跳加速。她不知道"他们"是谁，也不知道自己经历了什么，但她明白一件事：她的记忆不是自然消失的，而是被人故意夺走的。
```
