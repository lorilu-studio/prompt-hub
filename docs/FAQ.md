# 常见问题解答 (FAQ)

## 关于仓库

### Q: 这个仓库的目的是什么？
A: 本仓库旨在收集、整理和分享高质量的提示词，为AI使用者、开发者和研究人员提供全面的提示词资源。

### Q: 我可以如何使用这些提示词？
A: 您可以自由浏览、使用和修改这些提示词，但请遵守MIT许可证的规定。如果您在商业项目中使用，建议注明来源。

### Q: 如何找到适合我需求的提示词？
A: 您可以通过以下方式查找：
1. 按类别浏览：在 `categories/` 目录中按类别查找
2. 使用标签搜索：根据标签关键词搜索相关提示词
3. 使用GitHub搜索功能：搜索特定关键词

## 关于贡献

### Q: 我如何贡献新的提示词？
A: 请查看 [贡献指南](docs/CONTRIBUTING.md) 了解详细的贡献流程和规范。简单来说，您需要Fork仓库，创建分支，按照规范添加提示词，然后提交Pull Request。

### Q: 贡献的提示词有什么要求？
A: 我们要求提示词：
1. 实用性强，能解决实际问题
2. 清晰明确，易于理解和使用
3. 格式符合仓库规范
4. 包含完整的使用指南和示例

### Q: 我可以贡献翻译版本的提示词吗？
A: 可以！我们欢迎多语言版本的提示词。请在元数据中正确标注语言，并在文件名中包含语言标识（如 `creative-story-starter-zh.md`）。

## 关于使用

### Q: 这些提示词适用于哪些AI模型？
A: 大多数提示词设计为通用型，适用于多种AI模型。每个提示词的元数据中会标注最适合的目标模型，如GPT-3.5、GPT-4、Claude等。

### Q: 提示词没有产生预期结果怎么办？
A: 可以尝试以下方法：
1. 检查是否按照提示词要求提供了正确的输入
2. 尝试微调提示词，使其更符合您的具体需求
3. 查看提示词的使用技巧和注意事项
4. 在Issue中反馈问题，我们会帮助您解决

### Q: 我可以修改提示词吗？
A: 可以！我们鼓励您根据具体需求修改提示词。如果您认为修改后的版本对其他人也有帮助，欢迎提交Pull Request分享您的改进。

## 关于技术问题

### Q: 如何在本地使用这个仓库？
A: 您可以克隆仓库到本地：
```bash
git clone https://github.com/您的用户名/prompts.git
```

### Q: 如何保持仓库更新？
A: 如果您已Fork仓库，可以定期同步原始仓库的更新：
```bash
git remote add upstream https://github.com/原始仓库/prompts.git
git fetch upstream
git merge upstream/main
```

### Q: 我可以请求添加新的提示词类别吗？
A: 可以！请在Issue中提出您的建议，说明新类别的必要性和适用范围。我们会评估并考虑添加。
