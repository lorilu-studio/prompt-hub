# 提示词收集仓库 (Prompt Collection Repository)

欢迎来到提示词收集仓库！这是一个专门用于收集、整理和分享高质量提示词的资源库。

## 📖 仓库简介

本仓库旨在为AI使用者、开发者和研究人员提供一个全面的提示词资源库。无论您是初学者还是经验丰富的用户，都可以在这里找到适合各种场景的提示词，并贡献自己的创意。

## 🗂️ 目录结构

```
prompts/
├── categories/          # 按类别分类的提示词
│   ├── writing/        # 写作相关提示词
│   ├── coding/         # 编程相关提示词
│   ├── analysis/       # 分析研究提示词
│   ├── creative/       # 创意生成提示词
│   ├── education/      # 教育学习提示词
│   └── business/       # 商业应用提示词
├── templates/          # 提示词模板
├── examples/           # 实际应用示例
├── docs/              # 文档和指南
└── assets/            # 相关资源文件
```

## 🚀 如何使用

### 浏览提示词
1. 进入 `categories/` 目录，根据您的需求选择相应类别
2. 每个类别下都有按子分类组织的提示词文件
3. 查看文件内容，找到适合您需求的提示词

### 使用提示词
1. 复制您感兴趣的提示词
2. 根据您的具体需求进行适当修改
3. 在AI模型中使用修改后的提示词

### 贡献提示词
1. 查看 [贡献指南](docs/CONTRIBUTING.md) 了解详细信息
2. 使用提供的 [模板](templates/) 格式化您的提示词
3. 提交Pull Request，分享您的创意

## 📝 提示词格式

本仓库使用统一的Markdown格式来组织提示词：

```markdown
---
title: 提示词标题
category: 分类
tags: [标签1, 标签2, 标签3]
author: 作者名
date: 创建日期
description: 简短描述
---

## 提示词内容

这里是实际的提示词文本...

## 使用示例

示例说明如何使用这个提示词...

## 变体与扩展

相关的变体和扩展提示词...
```

## 🔍 搜索和筛选

您可以使用以下方式快速找到需要的提示词：

1. **按类别浏览**：在 `categories/` 目录中按类别查找
2. **标签搜索**：使用标签关键词搜索相关提示词
3. **关键词搜索**：使用GitHub的搜索功能搜索特定关键词
