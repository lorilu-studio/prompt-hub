## 示例1：使用创意故事开头生成器

### 场景
您是一位小说作者，正在开始一部新的科幻小说，但缺乏创作灵感。

### 使用步骤

1. **选择提示词**
   访问 `categories/writing/creative-story-starter.md`，复制提示词内容。

2. **准备输入**
   根据提示词要求，准备以下输入：
   ```
   故事类型：科幻悬疑
   主角特点：一位失去记忆的科学家
   背景设定：2150年的月球研究基地
   关键元素：一本神秘的日记，一段无法解释的录音
   ```

3. **应用到AI模型**
   将准备好的输入填入提示词，然后发送给AI模型。

4. **获取结果**
   AI模型将生成一个引人入胜的故事开头，您可以基于此继续创作。

5. **迭代优化**
   如果对结果不满意，可以调整输入要素，如改变故事类型或主角特点，然后重新生成。

### 实际应用示例

**输入：**
```

故事类型：科幻悬疑
主角特点：一位失去记忆的科学家

1. 立即吸引读者注意力

**输出：**

## 重构后的代码示例

```javascript
/**
 * 计算购物车中所有商品的总价格
 * @param {Array} items - 商品数组，每个商品应包含price和quantity属性
 * @returns {number} 总价格（保留两位小数）
 * @throws {Error} 当输入无效时抛出错误
 */
function calculatePrice(items) {
  // 输入验证
  if (!Array.isArray(items)) {
    throw new Error('Invalid input: items must be an array');
  }
  
  if (items.length === 0) {
    return 0;
  }
  
  // 计算总价
  const total = items.reduce((sum, item) => {
    // 验证每个商品的有效性
    if (!item || typeof item.price !== 'number' || typeof item.quantity !== 'number') {
      throw new Error('Invalid item format: each item must have price and quantity properties');
    }
    
    if (item.price < 0 || item.quantity < 0) {
      throw new Error('Invalid item values: price and quantity must be non-negative');
    }
    
    return sum + (item.price * item.quantity);
  }, 0);
  
  // 处理浮点数精度问题
  return Number(total.toFixed(2));
}
```

- 代码可读性和可维护性有待提升
